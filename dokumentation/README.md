# Dokumentation

**AB_Aufgabenbeschreibung-Trainer-Assistent.docx** – Aufgabenbeschreibung für das
Intranet: Anleitung für Mitarbeitende, was die Module des Trainer-Assistenten tun
und wie sie im Alltag eingesetzt werden. Layout, Schriften und Aufbau folgen der
Vorlage „AB Aufgabenbeschreibung Service Call“.

Beim Öffnen in Word aktualisiert sich das Inhaltsverzeichnis automatisch
(alternativ: hineinklicken und F9 drücken), damit die Seitenzahlen stimmen.

`bilder/` enthält die im Dokument verwendeten Screenshots der App – nützlich,
wenn einzelne Abbildungen ausgetauscht oder für andere Zwecke gebraucht werden.
